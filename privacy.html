Политика конфиденциальности — Password Manager

Дата вступления в силу: 6 июля 2026 г.

1. Общие положения

Приложение «Password Manager» (далее — «Приложение») предназначено для локального хранения паролей и конфиденциальных данных на устройстве пользователя. Настоящая Политика конфиденциальности описывает, как Приложение обращается с данными пользователя.

2. Какие данные обрабатываются

Приложение хранит вводимые пользователем данные (названия сайтов, логины, пароли, заметки) исключительно локально, в зашифрованном виде, в памяти устройства пользователя. Приложение не собирает, не передаёт и не хранит персональные данные на внешних серверах.

При использовании функции автозаполнения Приложение временно получает от операционной системы Android структуру полей ввода (логин, пароль, адрес страницы) исключительно для сопоставления с сохранёнными записями и подстановки учётных данных. Эти данные обрабатываются в реальном времени, не сохраняются в постоянную память и не покидают устройство.

3. Где хранятся данные

Все данные хранятся только на устройстве пользователя. Данные защищены шифрованием с использованием мастер-пароля, который известен только пользователю. Разработчик не имеет доступа к этим данным и не может их восстановить в случае утери мастер-пароля.

4. Передача данных третьим лицам

Приложение не передаёт никакие данные третьим лицам. Приложение не использует аналитику, рекламные сети, трекеры или иные средства сбора данных. Приложению не требуется доступ к интернету для основной работы.

5. Безопасность

Данные шифруются на устройстве. Для дополнительной защиты в приложении включён запрет на создание скриншотов и отображение содержимого в списке недавних приложений. Буфер обмена автоматически очищается после копирования конфиденциальных данных.

Приложение поддерживает настраиваемую автоблокировку сесии и хранилища.

6. Используемые разрешения

Приложение запрашивает следующие разрешения Android:

  • Биометрия — для входа в приложение по отпечатку пальца. Данные отпечатка обрабатываются исключительно операционной системой; Приложение не получает к ним доступа.
  • Служба автозаполнения — системное разрешение для работы автозаполнения через Android Autofill Framework. Предоставляется автоматически при выборе Приложения в качестве службы автозаполнения в настройках Android.
  • Служба специальных возможностей — для резервного режима автозаполнения в приложениях и браузерах, не поддерживающих Autofill Framework. Требует ручного включения пользователем в разделе «Специальные возможности» настроек Android.

Приложение НЕ запрашивает доступ к интернету, контактам, местоположению, журналу вызовов, SMS, камере, микрофону, хранилищу (кроме собственного изолированного каталога) или любым другим данным за пределами своей «песочницы».

7. Права пользователя

Пользователь полностью контролирует свои данные и может удалить их в любой момент, удалив записи или само Приложение.

8. Изменения в политике

В случае изменения настоящей Политики обновлённая версия будет опубликована по этому же адресу.
